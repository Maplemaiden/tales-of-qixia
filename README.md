# Tales of Qixia（栖霞诡事）

中式民俗恐怖 · 2D 横版悬疑解谜。

Demo：四幕（破封 → 发现 → 讲述 → 合棺），Godot 4 + GDScript。

## 打开工程

1. 安装 **Godot 4.7.x**（与全组锁定同一小版本）
2. Godot → Import → 选择仓库里的 `game/`
3. 运行主场景（F5）：`scenes/act1/ward_1a.tscn`

操作：`A/D` 移动 · `E` 调查 · `Space` 继续对白
