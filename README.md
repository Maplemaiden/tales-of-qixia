# Tales of Qixia（栖霞诡事）

中式民俗恐怖 · 2D 横版悬疑解谜。

Demo：四幕（破封 → 发现 → 讲述 → 合棺），Godot 4 + GDScript。

**现行策划源头：** `吓人喵喵策划方案/`（2026-09-27 剧情初稿 + 玩法 / UI / 美术方案）。旧根目录 PDF 仅作存档，冲突时以该文件夹为准。

## 打开工程

1. 安装 **Godot 4.7.x**
2. Godot → Import → 选择仓库里的 `game/`
3. F5 从开场警告跑（默认窗口 1280×720；右上角可切全屏）

操作：`A/D` 移动 · `E` 调查 · `Space` 继续 · `Tab` 手记 · `H` 香火
