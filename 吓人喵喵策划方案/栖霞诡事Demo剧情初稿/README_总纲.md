### 0.2 三条总写作纪律

1. **只给现象，不给原因。** 玩家能看到抓痕、嫁衣、倒挂的面具，但看不到「谁做的、为什么」。
2. **不抒情。** 大脑会把修辞当成答案。所有抒情句（「可怜的姑娘啊」）一律删除。
3. **不解释二次。** 同一个信息如果出现第二次解释（台词说完道具又说），删掉后出现的那次。

## 1. L0 背景设定层（创作者内部资料 · 不直接进游戏）

### 1.1 一句话世界观

> 1935 年，一个寄养在岭南园宅里的十八岁姑娘，因为族里一条「规矩」被活活钉进了一口双人棺；七年后日军占了这座宅子，打破了压着她的东西，于是每一个「看见」这件事的人，都按同样的方式死去。

### 1.2 时代背景

- **现在时态**：1942 年（民国三十一年）深秋，抗战时期。
- **过去时态**：通过第三方资料、口述、实物倒推到 1935 年秋，时间跨度 27 年。
- **关键历史逻辑**：1938 年日军占领后，仙馆被征用为**前线临时驻扎点与伤兵转运站**（不是正规野战医院——这条已在策划方案中修正，写剧本时不要写成 hospital）。

### 1.3 地理设定：栖霞仙馆四区域

| 区域 | 建筑特征 | 叙事功能 | Demo 是否出现 |
| --- | --- | --- | --- |
| 前院祠堂 | 岭南祠堂，青砖灰瓦，镬耳墙，祖宗龛 | 宗族权力的视觉象征；被改为临时病房 | 是（第一幕病房） |
| 中庭洋楼 | 西式两层，满洲窗，趟栊门 | 起居与办公；日军驻扎后的指挥与验尸之所 | 是（第二幕办公室） |
| 后园经堂 | 供佛像，香火，百年榕树，傩面具规律 | 信仰的双重性：既能镇压也能超度 | 是（第三幕经堂） |
| 地下密室 | 洋楼暗门进，石墙，湿冷 | 死亡现场，全作恐怖核心 | 是（第一、四幕） |

### 1.4 超自然设定（写剧本时必须遵守的三条）

**① 横死不得超生**
非自然死亡者不得入祖坟、不得享香火，魂魄困于死亡之地。她是「被活埋」，属最惨烈的横死，因此怨气七年不散——**不是因为她怨念深，而是因为规矩不允许她走**。

> 对本 Demo 的约束：任何一句「她的怨气太重了」都写错误，麻烦不能归因于情绪。

**② 依附于怨灵**
她的怨气吸附了三类孤魂：早年死于仙馆的人、日军占领后死于仙馆的伤兵、被日军挖出来的无主尸骨。所以「是他们重演，不是她一个人动手」。

> 对本 Demo 的约束：田中和山本**都不是被她亲手杀死**，是被怨气「重演合棺体验」而死。这解释了为什么两人死状一模一样。

**③ 怨气四机制**

| 机制 | 含义 | Demo 中的实例化 |
| --- | --- | --- |
| 外溢 | 怨气从合棺向周围扩散 | 粤曲、红影、门窗自开、灵异现象 |
| 重演 | 让接近真相的人体验死者的死亡过程 | 田中之死、山本之死（死状一致） |
| 标记 | 标记「看见」真相的人 | 「你看见了吗？」——日记被污染 |
| 预知 | 将死之人看见「下一个与仙馆结缘的人」 | 山本死前看到撑伞女子 |

## 2. 叙事方案：旁白 / 背景介绍 / 独白的三分法

### 2.1 背景介绍四方式对比（含推荐）

| 方式 | 泄漏风险 | 沉浸影响 | 工作量 | 是否采纳 |
| --- | --- | --- | --- | --- |
| 开场历史提要卡 | 中 | 打断入场节奏 | 极低 | ✗ 不采纳 |
| 游戏内可查词条 | 低 | 正向，补齐手记界面 | 中 | ✓ 采纳 |
| 幕间短旁白 | 低 | 正向，强化档案质感 | 极低 | ✓ 采纳（并入冷旁白） |
| 不做显式介绍 | 零 | 最沉浸，但泛用户吃力 | 零 | ✗（作为回滚选项保留） |

**推荐组合理由**：这两种与你选的「第三方冷旁白」共用一套语法——冷旁白给人时间轴，词条给人名词，两者都不碰因果。

### 2.2 第三方冷旁白 · 规格

| 项目 | 规定 |
| --- | --- |
| 人称 | 无人称。不用「我」「我们」「你」 |
| 时态与口吻 | 陈述已成事实，纪录片式，冷，短句。**不抒情、不评价、不解释因果** |
| 音色 | 中年男声，无起伏，不加混响，不与音乐同轨（演奏是雨声） |
| **总量上限** | **全 Demo ≤ 8 句，合计 ≤ 120 字**。超过就是解释过度了 |
| 出现时机 | 幕开场、幕结束、跨越时间的转场（如「三日后」） |
| **禁用场景** | 幻象内（三层幻象全部禁止旁白）、她的穿插片段内、任何角色正在说话时、任何死亡演出过程中 |
| UI 呈现 | 仿宋 16pt，灰白 #C8C0B8，屏幕中下位，墨晕 0.3 秒淡入，无角色名（这是与字幕的最明显区别：字幕有角色名、楷体加粗暗金色；旁白没有） |

### 2.3 三种「声音」的对照

| | 冷旁白 | 角色独白 | 她的空灵声 |
| --- | --- | --- | --- |
| 位置 | 屏幕中下 | 屏幕中央偏上 | 无固定位置（随声源） |
| 字体 | 仿宋 | 楷体斜体 | 宋体，字间距放宽 |
| 有角色名吗 | **无** | 无 | 无（Demo 里她不该有名字） |
| 说什么 | 时间、地点、已成事实 | 此人在想什么 | 感受，从不给答案 |
| 字数线 | ≤ 40 | ≤ 28 | ≤ 12 |
| 总条数 | 8 | 约 25 | 7 |

## 3. L1 幕结构层

### 3.1 四幕总表

| 幕 | 标题 | 时长 | 视角 | 强度 | 核心事件 | 情绪出口 |
| --- | --- | --- | --- | --- | --- | --- |
| 一 | 破封 | 10–15 min | 田中 | ★★★★☆ | 养病 → 灵异 → 贪婪 → 破封 → 被杀 | 震惊 |
| 二 | 发现 | 12–15 min | 山本 | ★★★☆☆ | 清点 → 发现尸体 → 喘息 → 汇报封锁 | 困惑 |
| 三 | 讲述 | 12–15 min | 山本 / 她穿插 | ★★★★☆ | 逼问 → 挤牙膏讲述 → 劝告 → 辱骂 → 日记被污染 | 不安 |
| 四 | 合棺 | 20–25 min | 山本 / 她幻象 | ★★★★★+ | 三层幻象 → 合棺体验 → 被杀 → 地缚灵 → 钩子 | 恐惧转悲悯 |

### 3.2 因果链

```
1935：族人按“规矩”决定了一场冥婚 → 她被钉入合棺 → 横死不得超生
                                      ↓（怨气被困七年）
1938：日军入驻 → 镇压平衡被打破 → 怨气外溢
                                      ↓
1942 夜：田中贪念起 → 被蛊惑抹去法阵 → 封印破 → 怨气重演合棺 → 田中死
                                      ↓
次日：山本验尸（看见）→ 被标记 → 拒绝劝告 → 主动下密室 → 看见全部 → 山本死
                                      ↓
死后：山本成为地缚灵，依附于她；预知幻象指向下一个来的人
```

**两条「性格悲剧」**：田中死于贪婪，山本死于傲慢。两人都有逃生的机会，都因为自己的性格缺陷没走成。这是 Demo 的道德内核，写每一句台词时都要对照它。

### 3.4 双视角穿插

第三幕采用「三段山本 + 一段她」的交替。她的内容在 Demo 里**总量只有 10–15 秒**，而且只有嫁衣下摆、苍白的手、钉棺声、一句台词。留白的关键就在这里：玩家想看她的脸，但不给。

### 3.5 Demo 要验证的三个假设

| 假设 | 验证段落 | 成功信号 |
| --- | --- | --- |
| 合棺体验能打动玩家 | S4-5 | 通关后主动问「她是谁」 |
| 傩舞花旦鬼有辨识度 | S4-6 | 玩家想截图 |
| 双视角穿插不突兀 | S3-3 | 玩家不觉得跳戏 |

### 4.1 反泄题自检（写作时每场必过）

写完一个场次，问自己三句：

1. 玩家读完之后，**知道的变多了，还是疑问变多了？** — 变多了才对。
2. 这一场里有没有人**替玩家做总结**？（如「所以这是个怨灵复仇」）— 有就删。
3. 有没有出现**具象的决策者**？（族长、老爷、某个有名有姓的人）— 有就删。
