| 出口 | END-001「栖霞诡事 · Demo 完」 |

### 本幕要兑现的三件事

1. **重演机制必须被看见。**第一幕的七钉和 S4-5 的七钉在**音频结构上一模一样**——同一套声轨、同样的逐钉衰减、同样的心跳接管点。玩家会认出来：他正在经历一模一样的过程。这是「田中和山本死状一致」的答案。
2. **傩舞花旦鬼必须让人想截图。**美术规范把她列为 C 档手绘最高优先级，全 Demo 只有 S4-6 和 S4-7 给她正面机会。
3. **结尾必须转悲。**Demos 常常在最高的恐惧点收尾，本 Demo 不行——最后一格是「远处有人在哼曲」，余韵要落在她身上，不是山本身上。

### 一处必须先说清的连贯性

第一幕结尾，棺盖是**从外面被推开半寸**的，观众没看到里面（这一格在 2026-09-27 修订，见 `01_第一幕_破封.md` 的说明）。

所以 S4-1 那道缝第一次探进去时——**里面是空的**。田中的尸体早在第二幕出现在楼梯口了。

这不是 bug，是本幕的第一个有效惊吓：**她把这个东西挪出去了，盖子是从外面推开的。**玩家会想到，但没人给答案。这条线 Demo 不收，留给正篇。

代价是「棺内有更早的女性抓痕」这条线索被推迟到 S4-1 才揭，我认为这是好事——它在「完全没有预期的地方」出现，比第一幕给更有分量。

现有文档里碎片数量打架：

| 出处 | 写的数量 |

| UI 与文案设计方案（决策已落定） | **5 个拼合位**（上/下/左/右/中） |

**本项目按 7 走**（2026-09-27 定案），分配为：**第三幕经堂 2 块 + 第四幕密室 5 块 = 7**。

需要订正的两处「5」：

- 玩法设计 5.2.2 第一阶段「5 块（第三幕 2 + 密室 3）」→ 改为「**7 块（第三幕 2 + 密室 5）**」。
- 玩法设计 5.3 道具清单「傩舞面具碎片 ×5」→ 改为 **×7**。
- 玩法设计 5.4 密室段「共 5 块，第三幕已收集 2 块」→ 改为「**密室 5 块，总计 7 块**」。
- UI 与文案设计方案的拼合位：5 个（上/下/左/右/中）→ **7 个（上/下/左/右/左上/右上/中）**。
- 壁画贴图（NEW-04）按 **七个面具 + 中间一个人**绘制（六个围成一圈，第七块压在人身上）。

> 原本按 5 走是我在 v0.1 的裁定，依据是 UI 设计方案的「5 个拼合位」。现在改回 7，依据是**文案清单第 438 行本身就写了「第三幕 2 块 + 密室 5 块」**，且玩法设计两处、A4-022 一处都是 7——多数口径在 7 这边，只是拼合位那一处漏改。改回 7 的代价是壁画要从 5 个面具重画为 7 个（NEW-04 中成本），换来的是不用动三处已成文的文案。

至于「密室墙上七个反挂的傩面具」——那是**环境装置**，完整、不可拾取，不参与拼合。它留着，因为七这个数字在民俗上成立，而且视觉上好看。**拼的是另一样东西：复原台上的那一个。**

### 第一阶段 · 鬼影躲避拾取（3 min）

密室里有 **3 块**碎片，每块旁边一个鬼影——她是怨气的外显——沿固定路线缓慢巡逻。

**机制三条**

| 项 | 规则 |
| --- | --- |
| 视觉提示 | 鬼影背对时碎片发微光；鬼影面向时无光 |
| 听觉提示 | 鬼影靠近时**粤曲哼唱变强**，远离时变弱——用耳朵判断安全距离 |
| 死亡惩罚 | 碰到鬼影 → 画面被墨污吞没 → **回退到密室入口，不扣进度** |

第三条是本阶段的关键取舍：**不扣进度的死亡**是为了不让玩家因为怕丢进度而放弃探索，但每一次被抓都会重新走一遍那段黑走廊。恐惧来自重复，不来自惩罚。

### 与田中之死的区别（写在最前面）

两个人的死状**完全一样**，但过程必须完全不一样：

| | 田中 | 山本 |
| --- | --- | --- |
| 反抗 | 清醒但无力 | **清醒且奋力反抗** |
| 起身 | 没有 | **爆发力量翻出棺材** |

| 逃 | 没试过 | 撞门、拍门、跑到一半 |
