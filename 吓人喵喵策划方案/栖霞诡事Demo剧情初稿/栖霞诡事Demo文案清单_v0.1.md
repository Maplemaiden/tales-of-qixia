## 0. 文案总纲（写之前先对齐的五件事）

### 0.1 三条语气铁律

| 层级 | 适用 | 语气 |
| --- | --- | --- |
| 现实层 | 山本 / 田中的日常探索 | 白话、克制、短句。**不加感叹号**，恐惧靠断句和省略号，不靠标点 |
| 超自然层 | 幻象、穿插、被蛊惑 | 句子更短，大量「……」，允许重复（「放我出去……放我出去……」） |
| 旁白层 | 幕间、结局 | 极简，只陈述事实，不做评价、不抒情 |

### 0.2 四个人的语言特征

| 角色 | 语言特征 | 反面（不能写成） |
| --- | --- | --- |
| 田中 | 功利、具体、数字感强（军曹、章、分数）。口语带日语腔但不写日文假名 | 不要写成「为了大东亚圣战」这类口号 |
| 山本 | 医学术语 + 判断句，越崩溃句子越短 | 不要让他一上来就害怕，他的崩塌是渐进的 |
| 阿福伯 | 苍老、颤抖、挤牙膏。一句话被问三遍才吐一点 | 不要让他一次性讲完，也不要让他争辩 |
| 阿霞 | 空灵、悲怆、不给答案 | 不要让她解释因果，她只说感受 |

### 0.3 硬约束

- 对白单行 ≤ 18 字（对话框不换行）；独白 ≤ 28 字；旁白 ≤ 40 字。
- 标点：中文双引号 ""，省略号统一「……」，破折号「——」。禁止感叹号连用、禁止省略号后加句号。
- 禁止出现：现代网络语、英文单词、直白血腥描写、鬼魂自我介绍姓名。
- 全文不出现「阿霞」这个名字（Demo 阶段玩家不该知道她叫什么）——统一称「那个姑娘」「她」。

### 0.4 留白红线（文案**绝对不能**提前回答的 8 个问题）

1. 为什么有冥婚 2. 谁拍板的 3. 合棺里那个死人是谁 4. 法阵是谁画的 5. 她叫什么 6. 她为什么被选中 7. 莫婉清是谁 8. 那支曲子叫什么、为什么没唱完

> 检验方法：写完一条文案问自己——玩家读完会不会少一个疑问？会，就删。

### 0.5 命名与版本

- ID 规则：`模块-三位序号`，模块见下表；版本 `V01` 起，每次改动递增。
- 交付格式：本清单（Markdown）+ 一张总表（ID / 场景 / 类型 / 说话人 / 文案 / 字数 / 是否配音 / 状态）。
