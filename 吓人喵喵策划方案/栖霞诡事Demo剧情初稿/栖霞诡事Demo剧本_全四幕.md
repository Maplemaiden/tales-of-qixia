## 读法

**本剧本把「演绎」和「游玩」放在同一条时间轴上往下读，用标签区分，用交接句连起来。**

| 符号 | 含义 |
| --- | --- |
| ▼ | 一个节拍。带时间码和标签 |
| **【演绎】** | 不可操作的演出段。玩家在看 |
| **【游玩】** | 可操作段。玩家在操控山本 / 田中 |
| △ | 画面：这一段发生什么 |
| ▸ 图 | **这一段用哪几张图**。格式＝资产名｜尺寸｜shader 层｜来源 |
| ▸ 声 | 声景三层：底层 50% / 中层 30% / 顶层 20% |
| ▸ 交接 | 上一段怎么把控制权交给下一段。这是「串联」的关键 |
| ▸注 | 写给美术 / 音频 / 导演的补充说明 |

**关于「图」的标注口径**：每一处 `▸ 图` 列的是这一段画面里实际出现的资产。标注「已有」＝《美术与音频设计方案》+《美术规范文档》清单里已经有了；标注「NEW-xx」＝剧本推出来的新增项，全部汇总在文末。

**关于台词**：正文里保留的是可以直接录音的版本。全部 ≤18 字（对白）/ ≤28 字（独白）/ ≤40 字（旁白）。

# 第一幕 · 破封

**13 min ｜ 视角 田中 ｜ 强度 ★★★★☆ ｜ 情绪出口 震惊**

▸ **旁白 NAR-01/02**（位于 S1-1 开场）：民国三十一年，秋。雨下了七天。／这座宅子原是人家的宅院，如今住了兵。

> 本幕的三件小事：把田中的贪念讲**具体**（不是“立功”，是一张差一个章的申请表）；让灵异按「视觉异常 → 物体异动 → 自我认知错乱」三段累积；让玩家看着自己的手把封印抹掉。
