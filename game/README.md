# Godot Demo 灰盒说明

## 打开

1. Godot 4.7.x → Import → `Tgame/game`
2. F5 运行（从 1A 开始）

## 全流程（对齐剧情设计 v1.1）

```
1A 病房（照片+回国申请表）→ 1B 走廊(查3处)
 → 1C 法阵长按抹除 → 1D 合棺清醒钉死
 → 2 办公室/验尸/假进门/汇报
 → 3 阿福伯挤牙膏讲述+一闪穿插 → 3E 夜间日记污染
 → 4 五物(日记=回忆)+三层幻象+七钉+合棺挣扎之死
 → Demo CLEAR（R 重开 / Esc 退出）
```

| 段落 | 操作要点 |
|------|----------|
| 1A | E 起身 → 可选照片/申请表 → 左侧出门 |
| 1B | 查满洲窗/自开门/镜子 → 右侧下楼 |
| 1C | 查合棺 → **长按 E** 抹法阵 |
| 1D | 演出：棺内清醒 → 花旦鬼凝视 → 钉棺（自动） |
| 2 | 名单+护士 → 验尸 3 处 → 靠近密室门（假进入）→ 汇报 |
| 3 | 对话阿福伯（挤牙膏+一闪穿插）→ 劝告辱骂 → 自动进夜 |
| 3E | 写日记发现「你看见了吗？」→ 出门进密室 |
| 4 | 查 5 物 → 靠近阿霞 → 旁观二层 → **七次 Space/E** → 翻棺挣扎结局 |

操作：`A/D` 移动 · `E` 调查 · `Space` 继续

## 跳关调试（可选）

在 Godot 远程调试或临时改 `ward_1a.gd` 的 `goto_scene` 目标即可。  
或在任意场景脚本 `_ready` 开头 `goto_scene(ScenePaths.CHAMBER_4)` 测第四幕；  
测日记夜：`goto_scene(ScenePaths.DIARY_NIGHT)`。
