# Godot Demo 灰盒说明

依据：`吓人喵喵策划方案/`（2026-09-27 剧情初稿 + 玩法设计）

## 打开

1. Godot 4.7.x → Import → `Tgame/game`
2. F5（默认窗口 1280×720；右上角「全屏」或 F11 切换）

## 操作

| 键 | 功能 |
|----|------|
| A / D | 移动 |
| E | 调查 / 拾取 / 对话 |
| Space | 继续对白 / 七钉 |
| Tab | 手记 |
| H | 香火提示（每谜最多三问） |
| F1 | 调试跳关（数字键直达；会重置进度并补齐前置道具） |
| F11 | 全屏 / 窗口 |
| R | 结束页重开 |
| Esc | 退出全屏；跳关菜单打开时先关菜单；结束页（窗口下）退出游戏 |
